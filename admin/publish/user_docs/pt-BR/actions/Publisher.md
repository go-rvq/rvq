# Publicação

Um registro que vai para o site — uma página, uma postagem — é editado como
**rascunho**: o que é salvo não aparece no site até ser **publicado**.

- **Publicar** põe o registro, como está agora, no site.
- **Cancelar publicação** tira-o do site; o rascunho é mantido.
- **Republicar** põe no site as alterações feitas desde a última
  publicação.
- **Agendar** publica (ou despublica) o registro numa data e hora.

O status do registro aparece no topo do detalhe dele: *Rascunho*, *No ar*,
*Fora do ar*. Vários registros são publicados de uma vez pela listagem:
selecione-os e escolha **Publicar** entre as ações em massa.
