# Refazer os recortes

Refaz os recortes de todos os arquivos que o campo mostra, nos tamanhos dele
— em segundo plano: a coluna **Recortes** da lista diz até onde foi. Use
quando os recortes não estão como os tamanhos dizem (arquivos de antes dos
tamanhos, recortes feitos em outras medidas). Nada acontece enquanto os
recortes do campo já estão sendo refeitos.
