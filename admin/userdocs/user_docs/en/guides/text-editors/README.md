# Text editors

The texts of the admin — the body of a page or a post, the notes of an
answer, the body of an issue… — are written in one of two editors, by the
field:

- **[Rich text](01-rich-text/README.md)**: what you see is what is shown —
  its bar formats the text; tables, footnotes, links, link cards, formulas,
  diagrams and sections that fold have buttons of their own.
- **[Markdown](02-markdown/README.md)**: the text is written with marks
  (`**bold**`, `## Heading`, `| a | b |`…), as GitHub's; its preview shows
  how it will look.

Both make the same text: a formula, a diagram, a card written in one shows
the same in the other and on the site.

The **?** beside a field written in one of them opens its document here.
