# Editores de texto

Os textos do admin — o corpo de uma página ou de um post, as notas de uma
resposta, o corpo de um chamado… — são escritos num de dois editores,
conforme o campo:

- **[Texto formatado](01-rich-text/README.md)**: o que se vê é o que aparece
  — a barra formata o texto; tabelas, notas de rodapé, links, cartões de
  link, fórmulas, diagramas e seções recolhíveis têm botões próprios.
- **[Markdown](02-markdown/README.md)**: o texto é escrito com marcas
  (`**negrito**`, `## Título`, `| a | b |`…), como no GitHub; a prévia mostra
  como vai ficar.

Os dois fazem o mesmo texto: uma fórmula, um diagrama, um cartão escrito num
aparece igual no outro e no site.

O **?** ao lado de um campo escrito num deles abre o documento dele aqui.
