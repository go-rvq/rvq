# Restaurar as permissões

As permissões de um papel do sistema podem ser mudadas como as de qualquer
papel. **Restaurar as permissões** troca as que ele tem pelas originais — as
que a aplicação dá a ele: as acrescentadas saem, as retiradas voltam.

Os usuários do papel passam a poder, na hora, o que as originais permitem.

## Quando está disponível

Só nos papéis do sistema cujas permissões podem ser mudadas — não no
Administrador, que pode tudo.
