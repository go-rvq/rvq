# Reset the permissions

The permissions of a system role can be changed as any role's. **Reset the
permissions** puts the originals — the ones the application gives it — in
place of those it has: the ones added go, the ones taken come back.

The users of the role may, at once, what the originals allow.

## When it is available

Only on the system roles whose permissions can be changed — not on the
Administrator, who may do everything.
