# Localizations

A record kept in several languages has one **version per language** of the
site. This action makes the version of the record in another language, from
the one shown:

1. Open the record in the language it already has.
2. Choose **Localizations** in its menu (**⋯**).
3. Choose the languages to make it in, and confirm.

The new versions start as a copy of this one; edit each to translate it. The
versions of a record are shown as chips in its detail; a click opens the
version of that language.
