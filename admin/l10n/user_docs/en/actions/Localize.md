# Localize

Makes the versions of a record in other languages of the site, as copies of
the one it is opened from:

1. In the listing, open the menu of the row (**⋯**) of the record.
2. Choose **Localize**.
3. **From** is the language of the version copied; the languages the record
   is already in are shown beside it. Choose under **To** the languages to
   make it in, and confirm.

Each new version starts with the texts of the copied one, in its language:
open it and translate it. A language the record already has a version in
cannot be chosen.
