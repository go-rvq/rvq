# Alterar local

Move uma versão de um registro de um idioma do site para outro — quando foi
escrita no idioma errado, por exemplo.

1. Abra a versão a mover.
2. Escolha **Alterar local** no menu dela (**⋯**).
3. Escolha o idioma a que ela pertence e confirme.

Não é possível escolher um idioma em que o registro já tenha uma versão.
