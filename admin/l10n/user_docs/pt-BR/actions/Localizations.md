# Idiomas

Um registro mantido em vários idiomas tem uma **versão por idioma** do site.
Esta ação faz a versão do registro em outro idioma, a partir da que está
aberta:

1. Abra o registro no idioma que ele já tem.
2. Escolha **Idiomas** no menu dele (**⋯**).
3. Escolha os idiomas em que fazê-lo e confirme.

As novas versões começam como cópia desta; edite cada uma para traduzi-la.
As versões de um registro aparecem como etiquetas no detalhe dele; um clique
abre a versão daquele idioma.
