# Pessoas

> Quem está cadastrado na organização?

## O que mostra

- Quantas pessoas ativas a organização tem.
- As cinco cadastradas por último, com o documento; cada uma abre o cadastro dela.
- **Ver tudo** abre a lista das pessoas da organização.

## De onde vêm os dados

O cadastro de pessoas da organização (as excluídas ficam de fora).

## Quem vê

Quem pode listar as pessoas. No Painel de cada organização; os dados são só dela.

## Detalhes

- Grupo: **Organização**.
- O id dele, nas preferências de cada usuário: `orgs/people`.
