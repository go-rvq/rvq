# Notificações

Uma **notificação** é um aviso para você: uma transferência deixou uma
carteira com saldo negativo, um convite chegou… Ela fica guardada até você
lê-la.

- No **sino**, no alto da tela, estão as **não lidas** mais novas: um clique
  abre o que ela diz e a marca como lida; **Marcar todas como lidas** marca
  todas; **Ver todas** abre esta página.
- No seu **perfil** (o painel no alto), o widget **Notificações** mostra as
  não lidas; o botão de cada uma a marca como lida.
- Nesta página, em **Meu perfil → Notificações**, estão todas as suas — só as
  suas: ninguém vê as de outro.

## As abas

- **Não lidas** (a que abre primeiro), **Lidas** (com **Lida em**, quando
  você a leu) e **Todas**.

## Lida ou não lida

Na coluna das ações, à esquerda do menu **…**, um ícone marca a notificação
como **lida** (o envelope aberto) ou de novo como **não lida**; ele pede a
confirmação.

## Enviar uma notificação

**Enviar notificação**, no alto da lista, manda uma notificação a outros
usuários: escolha **Para** quem (um ou mais), escreva o **título**, o
**texto** e o **nível** (informação, aviso, erro). Ela aparece para eles
como você a escreveu — não é traduzida —, com a origem **Usuários**. Só quem
pode ver a lista de usuários a vê.

## Os filtros

- **Quando**: de uma data e hora até outra.
- **Período**: hoje, os últimos 7, 30, 90 ou 365 dias (hoje entre eles).
- **Origem**: **Sistema** — o que o sistema avisa —, **Usuários** — o que um
  usuário mandou — ou **Outras**.

## Sistema ou usuário

As notificações do **sistema** (o campo **Sistema** marcado) aparecem no
**seu idioma**: o título e o texto são traduzidos na hora em que você os lê.
A mensagem que um **usuário** manda aparece como ele a escreveu. A **Fonte**
diz quem a fez.

## Excluir

Excluir uma notificação a manda para a **Lixeira** desta página, de onde
ela pode ser restaurada.
