# Reverter para esta revisão

Faz o registro voltar a ser o que era na revisão escolhida. A mudança é um
novo salvamento: ela cria uma nova revisão, então as revisões posteriores à
escolhida não se perdem, e uma reversão pode ela mesma ser desfeita.

Abra a revisão e escolha **Reverter para esta revisão** no menu dela
(**⋯**).
