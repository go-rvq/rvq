# Revisões

Todo salvamento de um registro cria uma **revisão**: o que o registro
continha, quem o salvou, quando e de onde. As revisões são listadas das mais
recentes às mais antigas.

- Abra uma revisão para ver o registro como era então.
- Selecione duas revisões e escolha **Comparar selecionadas** para ver o que
  mudou entre elas — veja {%= admin.doc("actions/Diff").link %}.
- Volte a uma revisão com {%= admin.doc("actions/revert").link %}.
- Veja onde uma revisão foi feita com {%= admin.doc("actions/origin").link %}.
