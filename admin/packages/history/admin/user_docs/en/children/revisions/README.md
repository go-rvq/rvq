# Revisions

Every save of a record makes a **revision**: what the record held, who saved
it, when and from where. The revisions are listed newest first.

- Open a revision to see the record as it was then.
- Select two revisions and choose
  **Compare selected** to see what changed between them — see
  {%= admin.doc("actions/Diff").link %}.
- Go back to a revision with {%= admin.doc("actions/revert").link %}.
- See where a revision was made with {%= admin.doc("actions/origin").link %}.
