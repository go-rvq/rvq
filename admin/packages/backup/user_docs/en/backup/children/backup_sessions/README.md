# Downloads

The download sessions of a state: each time a program opened it with an
access key.

- **Opened**: when.
- **User**: the owner of the key.
- **Address** and **Program**: from where and with what (the `User-Agent`).
- **Expires**: when its token stops working — each renewal puts it off.
- **Files** and **Served**: what it downloaded.

A session you do not recognize: revoke its access key (the owner's profile ›
**Access keys**).
