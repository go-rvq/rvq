# Downloads

As sessões de download de um state: cada vez que um programa o abriu com
uma chave de acesso.

- **Aberta**: quando.
- **Usuário**: o dono da chave.
- **Endereço** e **Programa**: de onde e com quê (o `User-Agent`).
- **Expira**: quando o token dela deixa de valer — cada renovação o adia.
- **Arquivos** e **Servido**: o que ela baixou.

Uma sessão que você não reconhece: revogue a chave de acesso dela (o perfil
do dono › **Chaves de acesso**).
