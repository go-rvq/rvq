# Links

Os links de download (.tar.gz) de um state: quem criou, até quando valem,
quantas vezes foram usados, o último endereço e o programa.

O chip ao lado da expiração diz se o link está **ativo**, **expirado** ou
**revogado**. O link em si não aparece aqui: ele só é mostrado quando é
criado.

Um link que não deveria mais funcionar: **Revogar**.
