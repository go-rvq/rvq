# Publish

**Publish** puts the commits of your draft on the site: the visitors see the
site as it makes it. New styles and scripts reach the browsers at once — their
address changes with the version.

Publishing needs three things, and says when one is missing:

- **Every change committed** — commit or discard what is left.
- **The draft up to date with the site** — if someone published after your
  draft was made, use **Update**: their commits come into your draft, yours go
  on top, and your changes not committed stay. If both changed the same part of
  a file, the update is undone and the draft stays as it was: agree with the
  other person, or **Start over**.
- **The site with no changes made outside** — if a file of the site was
  changed out of this editor, nothing is overwritten: whoever runs the server
  has to look.

The draft is checked again before publishing, as for a commit.
