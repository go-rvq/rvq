# Commit

Um **commit** registra as alterações do rascunho, com uma **mensagem** que diz
o que elas são ("Ajusta o rodapé", "Nova página de serviços"). O commit leva o
seu nome e o seu e-mail e entra no **Histórico**.

- O commit ainda não muda o site: ele fica no rascunho até você publicar.
- Antes do commit, o rascunho é conferido: a página inicial de cada idioma é
  feita com ele. Se der erro — um template que não compila, por exemplo —,
  nada é registrado e o erro aparece, com o arquivo e a linha.
- Sem alterações, não há o que registrar.
