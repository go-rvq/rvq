# Publicar

**Publicar** põe os commits do seu rascunho no site: os visitantes passam a
ver o site como ele o faz. Os estilos e scripts novos chegam aos navegadores
na hora — o endereço deles muda com a versão.

Publicar pede três coisas, e diz quando falta alguma:

- **Todas as alterações com commit** — faça o commit ou descarte o que
  sobrou.
- **O rascunho em dia com o site** — se outra pessoa publicou depois que o
  seu rascunho foi feito, use **Atualizar**: os commits dela entram no seu
  rascunho, os seus vão por cima, e as suas alterações sem commit ficam. Se as
  duas mudaram o mesmo trecho de um arquivo, a atualização é desfeita e o
  rascunho fica como estava: combine com a outra pessoa, ou **Recomeçar**.
- **O site sem alterações feitas por fora** — se um arquivo do site foi mudado
  fora deste editor, nada é sobrescrito: quem cuida do servidor precisa ver.

O rascunho é conferido de novo antes de publicar, como no commit.
