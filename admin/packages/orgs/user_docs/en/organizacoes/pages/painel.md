# Dashboard

The dashboard of the organization: its widgets — the organization's (members, what waits, activity) and the ones other packages put in it —, all of that organization alone. It is a page of the detail of the organization, in the menu under it.

Each user customizes it for themself, as the home dashboard: drag the widgets and the sections, resize the widgets by their right edge, remove and add; the layout is the same for every organization.
