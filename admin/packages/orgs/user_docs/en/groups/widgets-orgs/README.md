# Organization

The widgets of an organization: who it is shared with, what waits and what happened. They are on the [Dashboard](../../organizacoes/pages/painel.md) of each organization, of it alone; other packages put theirs here too (the people, say).

- [Members](../../pages/widgets-orgs/members/README.md) — Who is the organization shared with?
- [Pending requests and invites](../../pages/widgets-orgs/pending/README.md) — Is a sharing waiting?
- [Recent activity](../../pages/widgets-orgs/activity/README.md) — What changed in the sharing?
