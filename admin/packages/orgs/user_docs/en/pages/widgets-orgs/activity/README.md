# Recent activity

> What changed in the sharing?

## What it shows

- The latest events of the sharing: invites, acceptances, roles changed, accesses taken away.
- Each one with whom and when, the newest first.

## Where the data comes from

The access history of the organization (the one of the action **Access history**).

## Who sees it

With the organizations shared. On the [Dashboard](../../../organizacoes/pages/painel.md) of each organization, by whom reaches it; the data is of it alone.

## Details

- Group: **Organization**.
- Its id, in the preferences of each user: `orgs/activity`.
