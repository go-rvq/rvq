# Organização

- [Membros](../../pages/widgets-orgs/members/README.md) — Com quem a organização está compartilhada?
- [Pedidos e convites pendentes](../../pages/widgets-orgs/pending/README.md) — Algum compartilhamento está esperando?
- [Atividade recente](../../pages/widgets-orgs/activity/README.md) — O que mudou no compartilhamento?
