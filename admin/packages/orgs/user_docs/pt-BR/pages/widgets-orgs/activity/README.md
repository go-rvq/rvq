# Atividade recente

> O que mudou no compartilhamento?

## O que mostra

- Os últimos acontecimentos do compartilhamento: convites, aceites, papéis mudados, acessos retirados.
- Cada um com quem foi e quando, os mais novos primeiro.

## De onde vêm os dados

O histórico de acessos da organização (o mesmo da ação **Histórico de acessos**).

## Quem vê

Com as organizações compartilhadas. No [Painel](../../../organizacoes/pages/painel.md) de cada organização, de quem a alcança; os dados são só dela.

## Detalhes

- Grupo: **Organização**.
- O id dele, nas preferências de cada usuário: `orgs/activity`.
