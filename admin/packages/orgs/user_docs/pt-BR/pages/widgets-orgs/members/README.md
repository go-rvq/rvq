# Membros

> Com quem a organização está compartilhada?

## O que mostra

- Quantos usuários e grupos alcançam a organização.
- Cada um, com o papel dele (Leitor, Editor…), os da organização primeiro.

## De onde vêm os dados

Os acessos do compartilhamento da organização.

## Quem vê

Com as organizações compartilhadas. No [Painel](../../../organizacoes/pages/painel.md) de cada organização, de quem a alcança; os dados são só dela.

## Detalhes

- Grupo: **Organização**.
- O id dele, nas preferências de cada usuário: `orgs/members`.
