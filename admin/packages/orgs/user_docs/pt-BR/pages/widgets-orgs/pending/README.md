# Pedidos e convites pendentes

> Algum compartilhamento está esperando?

## O que mostra

- Os pedidos que aguardam a confirmação do proprietário, por e-mail (marcados em laranja).
- Os convites que aguardam o aceite de quem foi convidado (em azul).
- Os mais novos primeiro, com a data.

## De onde vêm os dados

Os pedidos e convites do compartilhamento da organização.

## Quem vê

Com as organizações compartilhadas. No [Painel](../../../organizacoes/pages/painel.md) de cada organização, de quem a alcança; os dados são só dela.

## Detalhes

- Grupo: **Organização**.
- O id dele, nas preferências de cada usuário: `orgs/pending`.
