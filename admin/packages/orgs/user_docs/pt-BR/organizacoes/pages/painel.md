# Painel

O painel da organização: os widgets dela — os da organização (membros, pendências, atividade) e os que outros pacotes põem nele —, todos só dessa organização. É uma página do detalhe da organização, no menu sob ela.

Cada usuário o personaliza para si, como o painel inicial: arraste os widgets e as seções, redimensione os widgets pela borda direita, remova e adicione; a disposição vale para todas as organizações.
