# Histórico de acessos

Tudo o que aconteceu com o compartilhamento da organização, do mais recente
para o mais antigo, guardado para sempre: quando, o quê, para quem, o papel
(antes → depois, quando mudou) e por quem. Entre os eventos:

- **confirmação pedida ao proprietário**, **confirmado pelo proprietário**,
  **recusado pelo proprietário**, **confirmação expirada** — o e-mail ao
  proprietário e a resposta dele;
- **convidado**, **convite aceito**, **convite recusado** — o convite de um
  usuário;
- **acesso concedido**, **papel trocado**, **acesso revogado**;
- **transferência de propriedade pedida**, **propriedade transferida**;
- **entrou no grupo**, **saiu do grupo** — um membro de um grupo com acesso.
