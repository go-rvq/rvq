# Transferir propriedade

Dá à organização outro **proprietário**: escolha quem e o **papel que você
mantém** nela (ou **None**, para não manter nada).

O proprietário atual confirma por e-mail; depois o novo proprietário recebe
um convite nas notificações e, ao aceitar, a organização passa a ser dele —
o antigo proprietário ficando com o papel escolhido.
