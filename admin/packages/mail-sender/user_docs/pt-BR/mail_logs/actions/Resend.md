# Enviar de novo

Envia o e-mail outra vez, como ele foi: o mesmo assunto (sem repetir o
prefixo da configuração), o mesmo corpo, para os mesmos destinatários, na
mesma conversa — o cliente de e-mail o agrupa com o original. O novo envio
ganha o seu próprio registro na central.

## Quando está disponível

Só num e-mail sem nada ocultado: com valores sensíveis ou corpo oculto, o que
ele tinha não foi guardado.
