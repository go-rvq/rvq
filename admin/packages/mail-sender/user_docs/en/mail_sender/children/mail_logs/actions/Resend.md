# Send again

Sends the e-mail again, as it was: the same subject (the prefix of the
settings not repeated), the same body, to the same recipients, in the same
conversation — the mail client groups it with the original. The new sending
gets its own record in the central.

## When it is available

Only on an e-mail with nothing hidden: with sensitive values or the body
hidden, what it had was not kept.
