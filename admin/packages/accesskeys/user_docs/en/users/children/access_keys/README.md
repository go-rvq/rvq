# Access keys

The access keys of this user: codes automations — git, WebDAV, scripts —
sign in with in the user's name, each allowed only what it releases of what
the user may. Whoever may edit the user keeps them here; the user, in
{%= admin.model("my_access_keys").link %}, where all is explained.

A key's permissions release what the user may — `admin:posts:*`, `*` (all)
—, deny a part of it (`deny admin:posts:*:@delete`) or give it back
(`allow`); with none, the key reaches nothing. They are edited in the field
of the permissions, made of what the user may; explained there.
