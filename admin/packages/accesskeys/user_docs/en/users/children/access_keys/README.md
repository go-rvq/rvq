# Access keys

The access keys of this user: codes automations — git, WebDAV, scripts —
sign in with in the user's name, each allowed what the user may, but what it
denies. Whoever may edit the user keeps them here; the user, in
{%= admin.model("my_access_keys").link %}, where all is explained.

A key's permissions are denies — `deny admin:users:*`, one a line —, on top
of what the user may; explained there.
