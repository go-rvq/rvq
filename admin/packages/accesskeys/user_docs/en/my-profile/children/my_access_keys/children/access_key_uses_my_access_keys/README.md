# History

Each request made by the key: **when**, its **kind** (git, webdav, api), the
**method** and the **path**, how it **went** (200 done; 401, 403 refused),
the **address** and the **place** it came from, and the **program** that
made it. Read only: the history is not made nor changed. The same requests
are in the user's access log, grouped each half hour.
