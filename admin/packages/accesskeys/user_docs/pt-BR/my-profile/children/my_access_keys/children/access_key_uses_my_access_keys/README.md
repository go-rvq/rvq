# Histórico

Cada pedido feito pela chave: **quando**, o **tipo** (git, webdav, api), o
**método** e o **caminho**, o **resultado** (200 deu certo; 401, 403 foram
recusados), o **endereço** e o **lugar** de onde veio, e o **programa** que
o fez. Só se lê: o histórico não se cria nem se muda. Os mesmos pedidos
aparecem, agrupados a cada meia hora, no log de acesso do usuário.
