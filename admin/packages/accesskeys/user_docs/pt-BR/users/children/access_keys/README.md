# Chaves de acesso

As chaves de acesso deste usuário: códigos com que automações — git, WebDAV,
scripts — entram em nome dele, cada uma só dentro do que ela permite **e** do
que o usuário pode. Quem pode editar o usuário cuida delas aqui; o próprio
usuário, em {%= admin.model("my_access_keys").link %}, onde tudo é explicado.
