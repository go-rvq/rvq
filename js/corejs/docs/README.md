# corejs docs

Reference for the `corejs` front-end runtime. See the package
[README](../README.md) for the overview and build/dev commands.

- [Architecture](architecture.md) — bootstrap, the `Root` providers, and the
  server-driven template model (`componentByTemplate`).
- [Plaid](plaid.md) — the `plaid()` request builder and how an `EventResponse`
  is applied (portals, pushState, runScript, root template).
- [Components & directives](components.md) — GoPlaidScope, GoPlaidPortal,
  UserComponent, GoPlaidRunScript, `v-keep-scroll`, `v-assign`.
- [Forms](forms.md) — the reactive `form` / `locals`, field binding, and
  `objectToFormData` serialization.
